## Robotic Hand using Arduino

### Project Overview
Developed an Arduino-based robotic hand prototype designed to demonstrate basic hand and finger movements using electronic components and programmed control.

### Technologies & Tools
- Arduino
- C/C++
- Servo Motors
- Sensors
- Embedded Systems

### Key Contributions
- Worked on the hardware assembly and component integration.
- Programmed Arduino to control robotic hand movements.
- Tested and improved finger movement and coordination.
- Troubleshot hardware and software issues during development.
