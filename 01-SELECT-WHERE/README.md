# SQL – SELECT and WHERE

## Learning Objectives
- Retrieve data from database tables using SELECT.
- Filter records using WHERE conditions.
- Practice comparison and logical operators.
- Understand basic SQL data retrieval.

## Topics Covered
- SELECT
- SELECT DISTINCT
- WHERE
- AND
- OR
- NOT
- IN
- BETWEEN
- LIKE
- IS NULL

## Practice
SQL queries will be organized here using sample business datasets.

## Career Relevance
These concepts help Business Analysts and Operations Analysts retrieve and filter business data for reporting and analysis.
